# 주조 불량 분류 — 모델 실험 정리

> 평가지표: **macro F1** (7개 클래스: 정상, Short_Shot, Blow_Hole, Exfoliation, Stain, Deformation, 기타불량)

---

## 1. 한눈에 보는 결론

- **가장 좋은 모델**: 앙상블 `KNN 0.4 + RF 0.4 + 제품별 XGB 0.2`
  - CV 에서 KNN 단독보다 **+0.0023** (seed 42: 15번 중 11번 승, seed 7: 10번 승)
- 점수의 대부분은 **test 의 58% 가 train 에 값이 똑같은 샷(쌍둥이)** 이라서 나온다 → KNN 이 강한 이유
- 처음 보는 샷은 어떤 모델도 약하다 (불량 여부 AUC ≈ 0.75, group CV macro F1 ≈ 0.26–0.30)
- **불량을 더 잡으려 하면 macro F1 이 떨어진다** — CV 와 public 리더보드 모두 같은 결과
- 증강 · 판정 기준 조정 · 특징 추가 · 수도 라벨링 등 20가지 넘게 시도 → KNN 을 확실히 이긴 방법은 없음

## 2. 리더보드 결과 (public, 1,130샷 · 실제 불량 253개)

| 모델 | macro F1 | 정확도 | 불량 탐지율 | 불량 예측 수 | 오탐 (정상→불량) |
|---|---|---|---|---|---|
| 1회차 모델 | 0.5158 | – | – | 180 | – |
| RF + ExtraTrees + XGB 앙상블 + 클래스 가중치 | 0.5822 | 86.0% | 56.1% | 178 | 36 |
| **KNN** | **0.5890** | **86.9%** | 56.1% | 170 | **28** |
| ExtraTrees | 0.5768 | 86.1% | 55.3% | 174 | 34 |
| 탐지율 위주 모델 | 0.5643 | 82.7% | **71.5%** | 278 | **97** |

- 오탐 = 불량 예측 수 − (탐지율 × 253)
- 탐지율이 같은 모델끼리는 **오탐이 적을수록 macro F1 이 높았다**
- 탐지율 위주 모델은 불량을 39개 더 잡았지만 오탐이 69개 늘어 macro F1 이 떨어졌다

## 3. 데이터에서 알아낸 것

### 3-1. 쌍둥이 샷 (값이 완전히 같은 행)
- train 5,274샷 중 3,097샷이 다른 행과 값이 완전히 같다
- test 의 58% (public 57.1%, private 58.4%) 가 train 에 쌍둥이가 있다
- 쌍둥이 그룹의 95% 는 생산 순서상 **바로 옆 행** → 같은 샷이 두 번 기록된 것
- KNN(거리 가중)은 거리 0 인 쌍둥이를 그대로 찾아 정답을 가져온다

### 3-2. 클래스별 쌍둥이 비율과 F1 (앙상블, seed 42 / 7)

| 클래스 | train 샷 수 | 쌍둥이 비율 | F1 |
|---|---|---|---|
| 정상 | 4,092 | 60% | 0.92 |
| Short_Shot | 469 | 65% | 0.60 / 0.64 |
| Blow_Hole | 233 | 70% | 0.70 / 0.71 |
| Exfoliation | 198 | 44% | 0.44 / 0.45 |
| Deformation | 106 | **11%** | **0.31 / 0.32** |
| Stain | 100 | 69% | 0.69 / 0.73 |
| 기타불량 | 76 | **26%** | **0.25 / 0.27** |

→ 쌍둥이가 적은 **기타불량 · Deformation** 이 macro F1 을 깎는다

### 3-3. 제품별 차이

| 클래스 | 제품 1 | 제품 2 |
|---|---|---|
| 정상 | 2,429 | 1,663 |
| Short_Shot | 161 | 308 |
| Blow_Hole | 0 | 233 |
| Exfoliation | 198 | 0 |
| Deformation | 106 | 0 |
| Stain | 2 | 98 |
| 기타불량 | 54 | 22 |

- 같은 Short_Shot 이라도 제품 1 · 2 의 특징 패턴 상관 **0.07** (불량 전체 −0.01)
- 제품 1 불량: Spray_1_Time +1.21, Biscuit_Thickness −0.64 (정상 대비 표준편차 단위, 유형 무관)
- 제품 2 Short_Shot: Casting_Pressure +0.80, Velocity_2 +0.50

### 3-4. 제품 1 의 생산 기간 (Spray_1_Time)

| 생산 순서 구간 | 불량률 | Spray_1_Time 설정 |
|---|---|---|
| 초반 (~1,260) | 36–39% | 1.0 |
| 중반 (1,260 ~ 3,370) | 9–17% | 0.8 |
| 후반 (3,370 ~) | 1% | 1.2 |

- 제품 1 불량은 유형과 관계없이 Spray_1_Time 1.0 구간(초반)에 몰려 있다
- 기간 정보는 Spray_1_Time 에 이미 들어 있다 — KNN 이웃의 99.7% (제품 2 는 100%) 가 이미 같은 Spray_1_Time

## 4. 평가 방법

| 방법 | 의미 |
|---|---|
| random 5-fold | 리더보드와 비슷 (쌍둥이가 학습/검증에 나뉨) |
| group 5-fold | 쌍둥이를 같은 fold 로 묶음 → **처음 보는 샷** 실력 |
| 5-fold × 3회 = 15번 짝지어 비교 | 같은 fold 에서 두 모델 점수 비교 |

- **확실히 이김** = 평균 +0.01 이상 **그리고** 15번 중 12번 이상 높음
- 조합 · 설정은 seed 42 로 고르고, seed 7 로 다시 확인
- fold 하나당 점수 흔들림 ±0.03 → 0.005 미만 차이는 운으로 본다
- RF+ET+XGB 앙상블의 클래스 가중치 적용 점수(≈ 0.57)는 같은 데이터로 맞춘 낙관적 값, 공정하게 재면 ≈ 0.553

## 6. 탐지율 vs macro F1

| 모델 | CV 탐지율 | CV macro F1 (seed 42 / 7) |
|---|---|---|
| KNN | 48–50% | 0.555 / 0.574 |
| **앙상블** | 51–52% | **0.558 / 0.577** |
| 앙상블 + 정상 ×0.8 | 54–56% | 0.555 / 0.569 |
| 앙상블 + 정상 ×0.5 | 61–63% | 0.540 / 0.553 |
| KNN + SMOTE 1배 | 62% | 0.534 |
| 2단계 분류 | 64% | 0.521 |

탐지율을 올리면 오탐이 더 빨리 늘어 macro F1 이 떨어진다. public 리더보드에서도 같았다
(탐지율 71.5% → 0.5643 / 탐지율 56.1% → 0.5890).
