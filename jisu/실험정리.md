# 주조 불량 분류 — 모델 실험 정리

> 평가지표: **macro F1** (7개 클래스: 정상, Short_Shot, Blow_Hole, Exfoliation, Stain, Deformation, 기타불량)
> 최종 코드 `결과/main.py` · 최종 제출 `결과/제출_3조_최종.csv` (3회차, public 0.5890) · 보고서 `jisu/final/보고서_3조.pdf`

## 1. 한눈에 보는 결론

- **최종 모델: KNN** (MinMax · k=15 · 맨해튼 거리 · 거리 가중, train 5,274샷 전체로 학습)
  - 같은 5-fold(seed 7)에서 KNN 0.5825 · RF 0.5714 · PLR MLP 0.5342 · 로지스틱 0.1306
  - KNN 설정 84개 조합 중 1등 (5-fold × 3회, seed 42 평균 0.5551)
- 앙상블 `KNN 0.4 + RF 0.4 + 제품별 XGB 0.2` 는 KNN 보다 **+0.0023** (seed 42: 15번 중 11번 승, seed 7: 10번 승)
  → 채택 기준(평균 +0.01 이상 · 15번 중 12번 이상) 미달이라 **더 단순한 KNN 을 최종으로** 했다 (6회차로 제출, public 0.5858)
- 점수의 대부분은 **test 의 57.7% 가 train 에 21개 값이 모두 같은 기록(중복 기록)** 을 가져서 나온다 → KNN 이 강한 이유
- 처음 보는 샷은 어떤 모델도 약하다 (중복 기록 묶기 macro F1 ≈ 0.26–0.30, 시간순 0.138)
- **불량을 더 잡으려 하면 macro F1 이 떨어진다** — CV 와 public 리더보드 모두 같은 결과
- 증강 · 판정 기준 조정 · 특징 추가 · 수도 라벨링 등 20가지 넘게 시도 → KNN 을 확실히 이긴 방법은 없음

## 3. 데이터에서 알아낸 것

### 3-1. 중복 기록 (21개 값이 모두 같은 샷)
- train 5,274샷 중 3,097샷(58.7%)이 다른 train 샷과 21개 값이 모두 같다 (1,486묶음)
- test 의 57.7% (public 57.1%, private 58.4%) 가 train 에 같은 기록이 있다
- 1,486묶음 중 1,433묶음(96%)은 생산 순서상 **바로 붙어 있고**, 나머지도 2~3칸 안이다 → 같은 샷의 이중 기록이거나 설정이 같은 연속 샷 (데이터로는 구분 불가)
- 57묶음은 값이 같은데 정답이 다르다
- KNN(거리 가중)은 거리 0 인 같은 기록을 그대로 찾아 정답을 가져온다
  - 5-fold(seed 7)에서 학습 쪽에 같은 기록이 있는 샷 macro F1 0.831 (불량 563건 중 517건 탐지), 없는 샷 0.269 (619건 중 83건)

## 4. 평가 방법

| 목적 | 나누는 방식 | 설정 |
|---|---|---|
| KNN 설정 고르기 · 대안과 짝 비교 | 층화 5-fold × 3회 = 15번 | `RepeatedStratifiedKFold(5, n_repeats=3)`, seed 42 로 고르고 seed 7 로 확인 |
| 모델끼리 비교 · 혼동행렬 (보고서 3 · 9장) | 층화 5-fold 1회 | `StratifiedKFold(5, shuffle=True, random_state=7)` |
| 처음 보는 샷 | 중복 기록을 같은 fold 로 묶은 층화 5-fold | `StratifiedGroupKFold(5)` (memo 값 seed 42 · 보고서 값 seed 42 · 43 · 44 평균) |
| 리더보드 조건 vs 배포 조건 | 무작위 80/20 (층화, seed 42) vs 시간순 80/20 (shot_id 앞 80% → 뒤 20%) | `train_test_split(test_size=0.2, stratify=y, random_state=42)` |

- **확실히 이김** = 평균 +0.01 이상 **그리고** 15번 중 12번 이상 높음
- fold 하나당 점수 흔들림 ±0.03 → 0.005 미만 차이는 운으로 본다
- 같은 KNN 도 5-fold seed 만 0 ~ 20 으로 바꾸면 0.5466 ~ 0.5825 (80/20 은 0.4913 ~ 0.6120)
- RF+ET+XGB 앙상블의 클래스 가중치 적용 점수(≈ 0.58)는 같은 데이터로 맞춘 낙관적 값, 중첩 검증으로 다시 재면 ≈ 0.546
